# KangleipakGo Customer App

Starter Flutter MVP for Android, iOS, and Web.

## Included
- KangleipakGo home screen
- 795001 service-area banner
- Groceries, snacks, cosmetics, medicine categories
- Search and category filtering
- Sample products
- Basic cart counter
- Responsive product grid

## Run
1. Install Flutter.
2. From this folder run: `flutter pub get`
3. Run on web: `flutter run -d chrome`
4. Run on Android/iOS using a connected device or simulator.
